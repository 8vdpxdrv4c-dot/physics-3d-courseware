# 物理实验室 · 第一组交互样例

本组按资源总序号1–5依次包含凸透镜成像、平面镜成像、凸透镜考试探究、传送带受力分析和空间磁场；另保留杠杆附加页，使用相同的实验室风格、参数面板和相机手势。界面参考用户提供的深色光学实验室图片，三维仪器和交互程序重新编写。

右上角仅显示当前课程名称，点击后从下拉菜单切换课程，当前项显示勾选标记。支持方向键、Enter、空格及Esc；点击菜单外部收起。课程切换器封装在 `src/components/lesson-switcher.js`，独立样式与接入说明见同目录；由课程清单驱动，路由和实验状态由宿主页面管理。

左下角点击“画质：高画质 / 低画质”即时切换。高画质保留Bloom和最高4×多重采样；低画质关闭Bloom与多重采样（包括平面镜反射缓冲），适合运行较慢的设备。选择会被记住，切课或刷新后继续生效；切换画质保留当前视角和实验状态。

左右控制面板、典型状态和结果区域采用统一的半透明毛玻璃，场景从背后柔和透出，文字及操作控件保持清晰。低画质自动减小面板模糊半径。

远景使用生成的虚化实验室全景图，同一张PNG通过PMREM提供环境反射；图像随项目放在 `public/textures/`。光源改为三维蜡烛与GLSL体积火苗，清晰像同步显示缩放、倒立的烛身和烛焰。火焰摆动属于视觉效果，成像按固定参考点计算；减少动态偏好下火苗保持静止。

可见背景单独压暗、降低饱和度并柔化光斑高光，使仪器与标注更突出；原图继续提供环境照明和金属反射。背景调色仅在加载时处理一次，高低画质共用，不增加每帧后处理。

共享照明采用大面积柔光与室内反弹补光，暗色支架保留可见层次；金属粗糙度提高，集中高光与Bloom减弱。曝光仍为1.02，远景维持深色。柔光用于展示仪器形状，不表示烛焰提供了整间实验室的照明。

三维画布铺满浏览器视口，窗口与横竖屏变化时同步适配；标题和参数以浮层显示。窄屏点击右下角“实验参数”展开面板，在面板内部滚动，再点“收起参数”恢复观察空间。滚轮和双指缩放带连续阻尼与距离边界，松手后缓慢停下；不会改变实验中的实际尺寸。桌面使用程序化拉丝金属纹理，包含粗糙度、微凹凸和安装孔位。

真实光路、受力箭头、磁场线与探针方向使用GLSL流光；磁极反转时流向同步反转。流光仅示方向，不表示物体运动、场强或真实传播速度。尺寸线、主光轴和虚像延长线保持静态；减少动态偏好下保留静态方向指示。

## 本地运行

在此文件所在目录运行 `npm ci`，再运行 `npm run dev`，打开终端显示的本地地址。也可运行同目录的 `启动课件.ps1`。需要可用的 Node.js 与 npm；首次安装依赖需要网络，构建后的课件没有外部CDN依赖。

`npm run build` 生成 `dist/`，`npm run preview` 可预览构建结果。应通过本地HTTP服务运行；浏览器直接双击HTML通常不能加载模块和JSON。

直达入口：`/#/lens`、`/#/mirror`、`/#/lens-exam`、`/#/conveyor`、`/#/magnet`；附加页 `/#/lever`。切课后恢复该课件初始参数；调参保留相机；“复位视角”只恢复相机。左侧所有改变相机的按钮使用约0.85秒平滑过渡；连续改选从当前画面转向新目标，手动拖动或滚轮操作立即打断。减少动态偏好下缩短为约0.18秒。右下角独立视角工具栏已移除；可拖动旋转、右键平移、滚轮缩放，在非输入区域按R复位视角。

静态课件直接调参或选择典型状态。典型位移采用约0.75秒平滑过渡，不代表真实物理时间。凸透镜提供“光屏自动对焦”，虚像、焦点或导轨范围外的像不可自动对焦；杠杆保留“重置实验”；磁场提供“反转磁极”和“重置实验”。传送带提供开始、暂停、继续、0.5倍慢放和前进0.1秒，空格控制播放。重新放置保留参数，重置实验恢复默认参数；任何物理参数变更都回到初态并暂停，视角保留。

平面镜包含镜面观察、对称测量、光路追踪、光屏检验四个模式。物体可在水平面内拖动，光屏可拖动改变屏距；镜面观察显示实时反射，其余模式淡化镜面用于教学透视。光点播放仅沿实际入射/反射路径，静态紫色虚线是反向延长线；镜后虚像不能由光屏承接。重置实验保留当前模式与视角，详细约定见 `平面镜模型说明.md`。

## 模型范围

- 凸透镜：理想薄透镜和近轴光线；像距由物距、焦距计算，光屏位置独立。虚像不能被光屏承接；没有像差和衍射计算。
- 杠杆：水平轻杆的静力矩比较。未平衡时仍由约束保持水平，不模拟转动过程。
- 磁场：六种规定磁化/电流回路的定性模型；场线、探针和铁屑共用毕奥–萨伐尔叠加场。环形采用轴向磁化，蹄形由三段规定磁化近似；未求解铁磁材料响应。中央二维截面为z=0，铁屑板可沿z平移，其颗粒原地转向平面内分量。场强为相对值，线数不改变场强。内部透视仅为教学显示。

- 传送带：带速恒定，带长8米，物块按质点计算，静、动摩擦系数取同一值，g=9.8 m/s²。沿带向右为正方向（倾斜时向上）。滑动摩擦反抗相对滑动；同速时只有静摩擦足够才维持同步，水平同步无摩擦。到端点定格并保留离带前速度，不模拟后续掉落。详见 `传送带模型说明.md`。

- 平面镜：理想单面平面镜，物像按平面反射变换对应；以发光箭头中心参考线计垂直距离，厚度只作造型，不模拟折射、衍射、多镜反射与光强分布。透视造成的屏幕表观大小差异不等于物理像高变化。

## 扩展课件组

每个课件制作或重做前，先读教师/学生说明，再实际阅读OpenStax对应章节，核对公式、单位、适用条件和边界，记录修正项、直接链接、版本、查阅日期和验证案例，确定正确的开发目标后再开始实现。不同课题选择对应章节；杠杆的9.2章节不作为其他课题的通用依据。逐课校对写入开发目标记录，完成后按这些案例验收。

`public/batch.json` 管理组内入口与来源。共享样式位于 `src/theme.css` 与 `src/style.css`；共享实验场景位于 `src/stage.js` 与 `src/kit.js`；方向流光位于 `src/direction-flow.js`，缩放阻尼位于 `src/damped-zoom.js`，金属纹理位于 `src/metal-surface.js`；火苗位于 `src/flame.js`，图片生成记录位于 `public/textures/asset-provenance.json`。新课题需实现物理模型和场景，并在 `src/main.js` 注册参数、预设与操作。

已经安装的 `physics-3d-courseware` 技能包含同一公共模板、知识点检索脚本及模型/交互约定。这些模型是可修改的起点；新增知识点仍需建模和验证。平面镜的独立模型位于 `src/mirror-physics.js`；新实例可用脚手架参数 `--topics mirror`，或与其他课件ID组合。

物理计算可通过 `npm test` 检查；运行构建不代替浏览器交互和画面检查。

## 本轮重做

先逐项读取原站教师/学生说明并搜索校对，具体纠错、开发目标、来源与验收案例见 `前五课件开发目标.md`。

凸透镜的三仪器有独立坐标，光屏按有限边界接收光线；光屏失焦时显示模糊光斑。考试版焦距固定10 cm，提供调焦、屏高、透镜位移与虚像四道自编情境，展开解析后显示像距和倍率。透镜对焦采用0.35 cm的演示容差；烛台/屏高变化与镜头坐标统一参与计算。

传送带包含水平同速预设与静摩擦需求/上限；磁场包含六种磁体、内部透视、中央截面与铁屑轻敲。模板只包含当前可运行的源码和必要资源。
