# 深色实验室：视觉与交互约定

## 视觉语法

- 背景为深蓝黑实验空间，主体为有支撑、连接和尺度关系的仪器。利用冷色轮廓光、暖色局部光揭示形状。
- 深色涂层金属作支架，银色金属作导轨和活动部件，黄铜用于接头和刻度重点；透明玻璃需有厚度、反射和轮廓，不仅降低透明度。
- 光路和当前教学重点用金色，交互控件用蓝色；N/S极、受力方向等学科语义可增加颜色，并提供文本或形状区分。
- 色彩默认：背景 `#060d17`，面板 `#0b1726`，正文 `#d2e2f5`，次要文字 `#8ea6c1`，交互蓝 `#57b3ff`，重点金 `#f7c575`，边框 `#30465e`。
- 中文标题采用宋体风格，数值采用清晰的数字字体。高光和发光只用于解释结构或信息；重点标注在课堂投影条件下仍可辨认。
- 重要对象真实建模，近景检查支架、关节、导轨、接触、阴影、光路遮挡。仪器没有必要复制参考图每一颗螺丝，但要有可信的组装逻辑。

## 抗锯齿与缩小画面

标尺、导轨与刻度盘上的数字及单位使用固定在仪器局部坐标中的3D Tag（共享 `kit.tag3D`），随尺面透视和父对象一起转动，不随相机转向。水平尺面将文字平面旋转到尺面，立面刻度保持与立面平行；启用深度测试并留微小表面间距，避免穿透遮挡物或深度闪烁。数字使用带mipmap与适度各向异性过滤的文字贴图；不以逐帧朝向相机保持可读性。教师提示、物像名称和动态结果等独立说明标注按需保留朝向镜头的 `label`。

使用EffectComposer时，renderer的antialias选项不覆盖后处理离屏缓冲。高画质为HDR颜色与深度共同支持的采样数启用最高4×MSAA，保留HalfFloat缓冲、原有色调映射与曝光。设备不支持至少2×HDR多重采样时，高画质在OutputPass之后使用FXAA；其分辨率由composer随画布同步更新。

左下角提供“画质：高画质 / 低画质”文字按钮，点击即时切换；默认高画质，localStorage记住选择，切课和刷新后沿用。低画质不创建Bloom或抗锯齿pass，主场景及平面镜反射缓冲的samples均为0，renderer固定antialias:false，确保画布没有残留多重采样。高低切换时释放旧composer的passes与渲染目标，低画质保留RenderPass和OutputPass以维持曝光、色彩、环境反射及自定义火苗着色器的输出一致；不重置相机或物理状态。场景特有的多重采样目标通过stage.registerQualityTarget登记并在销毁时解除。文字按钮可用键盘激活，空格不会同时启停实验；窄屏与播放、参数按钮分开排列。

renderer与composer保持一致的像素比（当前上限2），CSS显示尺寸、实际绘制缓冲和相机投影随视口更新。检查默认视角与实际滚轮缩小后的斜边、细尺寸线、透明体和发光光路；不能只看近景或用提高Bloom掩盖锯齿。销毁舞台时释放后处理passes及其渲染目标。抗锯齿会增加GPU开销，按真实设备表现调整采样和像素比，不承诺任意缩小倍率下所有亚像素细节均可辨认。

## 金属桌面与地面

用到桌板或地面时，增加清晰但不过分抢眼的金属纹理。模板的 `src/metal-surface.js` 程序化生成可平铺的拉丝底色、微凹凸与粗糙度贴图，三者方向和密度一致；颜色贴图用sRGB，数据贴图保持线性。按表面实际宽深设置UV重复，启用适度各向异性过滤，避免缩远后闪烁。

实验桌默认带规则安装孔位；普通金属地面可传 `perforated:false`，保留拉丝而不强加孔位。孔位为表面示意，不模拟穿透几何。贴图表面应高于桌板倒角，检查没有被底层遮挡或发生深度冲突。以共享材质和贴图表现细节，保留柔和高光与暗部层次；不要只提高金属度冒充纹理。场景销毁时释放这些贴图与材质。

## 暗部层次与柔和高光

保留深蓝黑远景，但仪器背光面、底座与桌面需能分辨相邻表面。先在固定曝光下调整灯光与材质，不靠升降整体曝光同时补救暗部与亮部。

- 用大面积RectAreaLight补光和较明亮的半球地面色模拟室内反弹；保留定向主灯与接触阴影。补光代表展示用的室内照明，不等同于实验中的烛焰光源，也不宣称计算了真实全局照明。 在主体上方中央、前上、后上、左上、右上增加五盏PointLight，共用舞台管理；五灯均设置castShadow=false，distance=0、decay=2，使用无截断的平方反比衰减。灯位与仪器保持距离，以分散的中低强度交叠照明减少局部亮斑，侧后方补光优先照清立面与底座，避免将灯贴近表面。
- 深色涂层保留漫反射，不使用接近纯黑且高金属度的统一材质。当前支架色为 `#303d4e`、金属度0.28、粗糙度0.64；裸金属单独校准：普通金属金属度0.90、粗糙度0.38，银色金属1.00/0.32，黄铜0.98/0.40，铜砝码0.98/0.26；其环境反射强度分别为1.25、1.30、1.50、1.90。数值是本组起点，按对象与最终视角检查。
- 下调集中聚光灯和高饱和轮廓灯，以适当粗糙度扩展高光；裸金属用接近1的金属度和可辨认的环境反射，涂层保留漫反射。不能为压制亮斑把所有金属粗糙度统一调高，也不能靠自发光伪造金属反光。
- 当前曝光维持1.02，主灯190、暖灯90，柔光面板9×6、强度4.2，半球光2.35、地面反弹色#8b94a1；PMREM环境强度1.05。灯光单位和类型不同，不直接按强度数字比较亮度。可见背景强度0.32，配合独立的高光与饱和度调整，减少背景光斑对主体的干扰。 五个点光源强度依次为36、48、52、46、46，位置依次为(0,8.5,0)、(0,5.5,6)、(0,5.8,-6)、(-7,5.8,0)、(7,5.8,0)，为当前实验组的起始值，迁移到不同尺寸主体时重新检查。
- Bloom强度0.09、阈值1.6，仅保留火苗和教学重点的柔和辉光；降低Bloom不能代替修正过强的直接反射。桌面降低金属度并提高粗糙度，纹理与侧边需在常用视角可见。

固定相机和曝光，分别检查主灯、补光、环境反射与组合结果；再检查侧面、俯视或对象近景。三种课题至少覆盖深色支架、金属边缘、黄铜、玻璃/屏面与磁极色块。以真实浏览器画面判断，不以参数数值或直方图代替视觉检查。

## 背景与环境反射

用户追加要求：远景使用生成的虚化质感图片，并同时作为环境图。模板内置 `public/textures/laboratory-blurred-environment-v1.png`，生成提示与来源记录在同目录 `asset-provenance.json`。

- 生成匹配深蓝/暖金实验室的2:1等距柱状全景，远景自带摄影虚化；不把整张课件截图作为背景，不在背景图中烘焙可操作仪器、文字或光路。
- 背景使用equirectangular映射；同一图生成PMREM并赋给 `scene.environment`。背景与反射旋转一致；仅改变页面CSS背景不等同于设置环境反射。
- 裸金属显式绑定同一PMREM环境纹理，并复制scene.environmentRotation，按材质单独配置envMapIntensity；当前Three.js版本使用scene.environment而material.envMap为空时，会使用scene.environmentIntensity，不能只改材质强度而误以为已生效。铜砝码采用圆周连续曲面和细倒角，让亮边与环境明暗随视角变化；深色涂层与浅色屏面继续使用场景统一环境。切课复用反射纹理，舞台销毁时解除共享材质绑定再释放PMREM资源。
- 可见背景与环境照明分别控制。`laboratory-backdrop.js`在原图加载时用一次GPU绘制生成线性颜色的背景目标：饱和度保留0.62，按亮度使用柔和高光压缩 `color / (1 + 0.65 × luminance)`；背景强度0.32、额外模糊0.04。原图仍用于PMREM与金属反射，旋转保持一致；主体曝光、灯光和材质不随背景压暗。背景调色不加入每帧后处理，高低画质共用结果，销毁时释放背景目标。以保留实验室空间感、收敛黄白与蓝色光斑、突出仪器及标注为准，避免把背景变成抢眼的灯光展示。
- PNG为LDR图像，环境照明是风格近似，不宣称它是实测HDR照明。
- 将最终图放进项目并随模板交付；不能只引用临时生成目录。替换环境图后检查金属、玻璃和白色屏面，并核对资源释放。

## 箭头与路径流光

有明确方向含义的箭头尽量加入shader流光，帮助识别朝向；优先使用共享 `src/direction-flow.js`，避免每个课件另写不同节奏和亮度的流动效果。

- `kit.arrow`默认使用流光；特殊静态箭头可传 `flow:false`。定向路径使用 `kit.line(...,{flow:{speed,spacing,phase}})`，普通线默认静态。容器应先接入 `stage.root`，再创建这些对象，以获取本场景的共享时钟。
- 流光坐标沿起点至箭头尖端递增；折线/曲线按累计弧长插值，不用顶点序号控制流速。连续路径的短箭头使用匹配的路径偏移，以保持亮带衔接。方向反转必须跟随模型：当前磁场通过反转路径点顺序实现，着色器仍沿递增弧长流动，避免再次反转造成错误方向。
- 光学沿光源→透镜→光屏的真实光路流动，保留折射拐点和终止位置；虚像反向延长线、主光轴、焦点辅助线保持静态。受力箭头只用短流光强调朝向，不移动重物或杆体。磁场沿外部场方向流动，探针箭头同步跟随同一个B函数。
- 尺寸线、力臂标注、刻度、支架和没有单向含义的辅助箭头不加入流动。不能用视觉流光暗示力在运输、磁感线为粒子轨迹，或声称视觉速度是实际传播速度。界面保留“流光仅示方向”，详细说明放在模型帮助中。
- 箭头轮廓始终可见，使用柔和亮带与适度密度；不依赖强Bloom、闪烁或大量粒子。流光只更新uniform，不逐帧重建几何，不给装置投下无关箭头阴影。
- 一场景共用一个流光视觉时钟与ticker，和物理时间独立。减少动态偏好下停止流动、保留静态方向；标签页隐藏时不更新。隐藏全部方向指示后移除不再需要的ticker，清理材质与切课时解除注册。

实际检查固定相机下的两帧：流光应改变位置，箭头、仪器和物理读数保持一致。另核对磁极/电流反转、虚像状态、显示开关、动态偏好与切课，不能用构建成功代替着色器编译和流向检查。

## GLSL烛焰

- 光源由三维烛身、烛芯和程序化火苗组成。`src/flame.js` 在局部包围盒中光线步进，使用噪声密度、亮芯、外焰及轻微摆动；不是箭头或静态发光图片。
- 可见火苗与附近PointLight属同一光源对象，位置和轻微明暗变化同步。限制Bloom，使烛焰轮廓、烛芯和仪器边缘仍可辨认。
- 几何光学以固定的烛焰参考点计算；外观闪动不改变物距、像距与倍率。光屏上的烛身与烛焰按同一倍率翻转/缩放，在屏面边界内裁剪；失焦与虚像状态保持原有语义。
- 用 `stage.addVisualTicker` 更新视觉效果，和教学预设/物理时间控制分开。切课时解绑，标签页隐藏时停止，减少动态偏好下保持静止；不要每帧重建几何。
- 火苗是视觉效果，不宣称模拟燃烧流体或面光源的成像积分。将其写成通用模块，便于其他烛焰类实验复用。

## 共享布局

左上显示学科、课题和一句教学问题；组内入口位于顶部；左侧提供对象关注或视图工具，典型状态紧接左侧按钮组下方，使用同一纵向容器随按钮数量自动排列，空间不足时容器内滚动；主体留给实验装置；右侧集中参数、读数、辅助显示和主操作；下方显示观察结果。

左右面板、典型状态、结果区域与课程下拉框共用theme.css的毛玻璃参数：深蓝渐变底色alpha约0.48–0.66、淡蓝透明边框、细顶部内高光及柔和阴影。对背景使用backdrop-filter，高画质blur 14px、低画质8px、saturate 110%；quality-toggle将当前画质写入外壳data-quality，滤镜变量在外壳作用域解析，以确保半径随切换生效。面板内容保持完全不透明，输入框使用稍深半透明底色，次级文字仍清晰。小按钮复用面板底层，不重复添加模糊；不做全屏模糊或逐帧模糊动画。不支持backdrop-filter时回退为较实的深色底。桌面与窄屏共用质感，检查参数展开、菜单覆盖及观察结果的可读性。

3D canvas必须从浏览器视口左上角铺满整个窗口，随宽高自适应；不留标题带或右侧面板空栏，不以静态背景填补局部canvas。标题、视角按钮、参数和结果浮在三维画布上；窄屏参数用可展开/收起的浮层，并在面板内部滚动。页面与画布保持视口尺寸，避免横向挤压与重复页面滚动。

使用ResizeObserver和窗口尺寸事件更新渲染尺寸、DPR、后处理缓冲与相机投影。宽高比改变时保留相机姿态和实验参数，按观察区域调整构图；不能仅通过CSS拉伸旧绘制缓冲。实际测量canvas矩形应为 `(0,0,视口宽,视口高)`，桌面、竖屏、横屏都需检查。

## 操作语义

| 操作 | 约定 |
| --- | --- |
| 空白处拖动 | 旋转视角；物体可拖拽区域需与相机手势区分 |
| 滚轮/缩放 | 带阻尼地改变观察距离，不改变物理尺度；连续输入平滑累积 |
| 正视/立体/俯视 | 平滑过渡到目标视角，只改变相机，不改变实验参数 |
| 对象关注 | 相机与观察中心同步平滑过渡到对象附近 |
| 复位视角 | 平滑恢复初始相机，不重置实验 |
| 重置实验 | 恢复已声明的参数与时间状态；保留相机，除非名称明确说明全部重置 |
| 滑块与数字输入 | 双向绑定同一状态；显示单位；限制到有效范围；不能输入NaN |
| 预设 | 一组可解释参数；显示实际生效状态，不把已失效的预设继续标为选中 |
| 暂停 | 保留物理时间、位置与速度；不跳回初始状态 |
| 参数变更 | 默认保留相机；涉及速度/位置重置时明确说明原因与行为 |

按钮和输入有可访问名称与键盘焦点。快捷键不抢占数字输入。触屏保留可用控件尺寸；色彩标记辅以文字。

## 相机过渡

右下角不显示独立的立体、正视、放大、缩小、复位工具栏；保留左侧视角按钮、拖动旋转、右键平移、滚轮缩放及非输入区域R键复位。左侧按钮凡改变相机视角，一律加入动画过渡；R键复位沿用同一控制器。模板默认约850ms，使用首尾平缓的缓动，同时插值相机位置和观察中心；首次进入课题直接建立初始视角。

过渡可中途改选，从当前画面连续转向新目标。手动旋转、平移、滚轮缩放或拖动对象时立即取消过渡，交还控制；清除旧惯性，避免到达目标后继续漂移。相机动画独立于物理时间，即使静态模型没有持续渲染也须完成过渡。减少动态偏好下缩短为约180ms。

滚轮与双指缩放由 `src/damped-zoom.js` 单独处理，OrbitControls的旋转阻尼不负责缩放。输入只更新受最小/最大距离限制的目标半径，逐帧按实际时间指数收敛，松手后约数百毫秒柔和停下，不越过目标或在边界弹跳；同一批连续输入不能每次重新起步。触控双指平移仍可使用，拖动对象和视角切换取消未完成的缩放。减少动态偏好下加快收敛；静态场景完成后停止持续渲染，销毁时移除输入监听。

## 演示按钮的取舍

“开始演示”按实际场景决定，不要求整组都有。先说明按钮启动的具体过程：真实时间演化、明确的分步操作或有教学价值的状态序列；仅靠调参即可观察的静态模型无需自动轮播。需要播放时，提供与过程相符的暂停、继续和重置语义。

当前模板：凸透镜保留“光屏自动对焦”，不可承接的像禁用；杠杆直接调参和选择典型状态，保留“重置实验”；磁场保留“反转磁极”和“重置实验”；传送带有连续运动过程，提供开始/暂停/继续、慢放、单步与重新放置。装饰性烛焰摆动不作为设置开始按钮的理由。

## 按课题选择交互

- 光学：物距与焦距是输入，理论像距是派生结果；光屏位置是独立输入。真实光线碰到光屏终止，反向延长线与真实光线使用不同线型。焦点奇异状态明确处理。
- 杠杆：区分保持水平的静力比较与解除约束后的转动。若不求解动力学，不用随意旋转冒充物理响应。力臂是到力的作用线的垂距。
- 磁场：线密度控件只改变显示密度；改变场强、磁极或电流必须由模型决定。探针方向与场线使用同一场函数。流光可用于指向提示，但不表示粒子实体或磁体运动。
- 动力学：连续运动时分配稳定的矢量对照区域，并检查物块到行程端点时标注仍可见；速度数值与力的指示需有不同颜色和名称。窄屏保留直接播放/暂停入口。声明积分方法与时间步长，实时帧率不决定物理结果；初始条件、运行状态与视角分开管理。轨迹与图表共用模型时间。

## 验收提示

对照参考图检查：是否先看见仪器；主标题和金色重点是否清楚；面板是否与背景拉开；玻璃是否能辨认；材质是否有冷暖光层次；光路是否被UI或无关装饰遮住。

对每个控件实际操作一次；检查按钮文字与效果一致、调参不跳相机、复位不篡改模型。相机检查起点、中间画面、终点、快速改选与手动打断，并覆盖无持续动画的静态课题。移动端与桌面端都需实际查看，不能只凭CSS断言兼容。
